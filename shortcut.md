## Shortcuts

### Summary

| Name                   | Keymap         | Remarks           |
| ---------------------- | -------------- | ----------------- |
| Emoji                  | `:`            |                   |
| Headings               | `ctrl+H`       | see below         |
| Bold                   | `ctrl+B`       |                   |
| Italic                 | `ctrl+I`       |                   |
| Strikeout              | `ctrl+S`       |                   |
| Link                   | `ctrl+K`       | see below         |
| Unordered List         | `ctrl+L`       | see below         |
| Ordered List           | `ctrl+O`       | see below         |
| Task List              | `ctrl+J`       | see below         |
| Blockquote             | `ctrl+;`       | see below         |
| Horizontal             | `ctrl+shift+H` |                   |
| Code Block             | `ctrl+U`       | see below         |
| Inline Code            | `ctrl+G`       |                   |
| Insert Block to Before | `ctrl+shift+B` | wysiwyg & ir mode |
| Insert Block to End    | `ctrl+shift+E` | wysiwyg & ir mode |
| Table                  | `ctrl+M`       | see below         |
| Undo                   | `ctrl+Z`       |                   |
| Redo                   | `ctrl+Y`       |                   |
| Hide Edit              | `ctrl+P`       | sv mode           |
| Fullscreen             | `ctrl+'`       |                   |
| Move Block to Up       | `ctrl+shift+U` | wysiwyg & ir mode |
| Move Block to Down     | `ctrl+shift+D` | wysiwyg & ir mode |
| Remove                 | `ctrl+shift+X` | wysiwyg mode      |
| At User                | `@`            |                   |
| Mistyped               | `Backspace`    |                   |

### Headings `ctrl+H`

| Name    | Keymap                 |
| ------- | ---------------------- |
| Bigger  | `ctrl++`               |
| Smaller | `ctrl+-`               |
| H1-H6   | `ctrl+alt+1/2/3/4/5/6` |
| Menu    | `ctrl+H`               |

### Link `ctrl+K`

| Name                  | Keymap      |
| --------------------- | ----------- |
| Toggle Input and Link | `alt+Enter` |
| Toggle Input          | `Tab`       |

### List `ctrl+L/O/J`

| Name         | Keymap                               | Remarks                                            |
| ------------ | ------------------------------------ | -------------------------------------------------- |
| Indent       | `Tab`, `ctrl+shift+I`                | `Tab`: Caret must be at Zero                       |
| Unindent     | `shift+Tab`, `ctrl+shift+O`, `Enter` | `shift+Tab`: Caret must be at Zero, `Enter`: Empty |
| Toggle Check | `ctrl+shift+J`                       | Task List                                          |

### Blockquote `ctrl+;`

| Name                    | Keymap              | Remarks                                            |
| ----------------------- | ------------------- | -------------------------------------------------- |
| Move Caret to Top Start | `ctrl+alt+Enter`    | wysiwyg mode                                       |
| Move Caret to Top End   | `alt+Enter`         | wysiwyg mode                                       |
| Insert Blockquote       | `ctrl+shift+:`, `>` | `ctrl+shift+:`: Block Element, `>`: Inline Element |
| Toggle Blockquote       | `ctrl+;`            |                                                    |

### Code Block `ctrl+U`

| Name                        | Keymap      |
| --------------------------- | ----------- |
| Toggle Input and Code Block | `alt+Enter` |
| Hide Edit                   | `Escape`    |
| Select all Code Block       | `ctrl+A`    |

### Table `ctrl+M`

| Name                        | Keymap                   |
| --------------------------- | ------------------------ |
| Insert 1 above              | `ctrl++`                 |
| Insert 1 below              | `ctrl++`                 |
| Delete Row                  | `ctrl+-`                 |
| Insert 1 left               | `ctrl+shift++`           |
| Insert 1 right              | `ctrl+shift++`           |
| Delete Column               | `ctrl+shift+-`           |
| Left Alignment              | `ctrl+shift+L`           |
| Center Alignment            | `ctrl+shift+C`           |
| Right Alignment             | `ctrl+shift+R`           |
| Move Caret to Input         | `alt+Enter`              |
| Toggle Input                | `Tab`                    |
| Move Caret to Previous Cell | `shift+Tab`, `Backspace` |
| Move Caret to Next Cell     | `Tab`                    |
